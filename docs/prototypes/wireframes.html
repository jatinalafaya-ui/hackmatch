Design decisions
  • Log in is the first screen on both platforms (spec).
  • One card component for a person, reused in search and shortlist.
  • Navy brand color, white cards, amber focus ring, shared across web and mobile.
  • Every input has a visible label; errors appear above the form.
  • Web uses a top nav; mobile uses bottom tabs with the same three sections.
